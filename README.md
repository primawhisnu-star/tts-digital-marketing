# 🧩 TTS Interaktif: Digital Marketing (Edisi Pembelajaran)

[![Platform: Web](https://shields.io)](https://github.io)
[![License: MIT](https://shields.io)](LICENSE)

Sebuah aplikasi **Teka-Teki Silang (TTS) Online** interaktif yang dirancang khusus sebagai media pembelajaran kreatif untuk mata pelajaran **Digital Marketing**. Proyek ini dibuat menggunakan teknologi web murni (*pure web*) tanpa *framework* tambahan, sehingga sangat ringan dan cepat diakses oleh siswa melalui komputer maupun *smartphone*.

🎯 **Coba Aplikasi Langsung di Sini:** [Klik untuk Bermain TTS Online](https://github.io) *(Ganti dengan link GitHub Pages Anda)*

---

## 🚀 Fitur Utama

- **20 Soal Menantang:** Terdiri dari 10 soal Mendatar dan 10 soal Menurun yang mencakup materi inti pemasaran digital.
- **Koreksi Instan Terintegrasi:** Siswa dapat memeriksa jawaban secara mandiri dengan satu klik tombol; kotak otomatis berubah warna menjadi hijau jika benar dan merah jika salah.
- **Ringan & Responsif:** Menggunakan CSS Grid murni yang fleksibel untuk berbagai ukuran layar.
- **Tanpa Database:** Seluruh logika pemeriksaan berjalan di sisi klien (*client-side* JavaScript), membuatnya aman dan mudah di-hosting secara gratis.

---

## 📚 Cakupan Materi (Kosakata)

Game edukasi ini menguji pemahaman siswa mengenai istilah-istilah populer dalam industri digital, antara lain:
- *Search Engine Optimization (SEO) & Pay Per Click (PPC)*
- *Affiliate Marketing & Content Creation*
- *Inbound Marketing (Leads, Landing Page, E-book)*
- *Digital Analytics & Return on Investment (ROI)*
- *Social Media Marketing (Influencer, Hashtag, TikTok, WhatsApp)*

---

## 🛠️ Teknologi yang Digunakan

Proyek ini dibangun dengan struktur kode yang bersih, terpisah, dan mudah dipelajari oleh pemula:
1. **HTML5** – Sebagai kerangka struktur papan (grid) dan daftar pertanyaan.
2. **CSS3** – Mengatur estetika tampilan visual, warna indikator koreksi, dan tata letak grid 15x15.
3. **JavaScript (ES6)** – Mengendalikan logika pembuatan grid dinamis secara otomatis dan algoritma pencocokan jawaban.

---

## 💻 Cara Menjalankan Secara Lokal

Jika Anda ingin mengunduh dan memodifikasi proyek ini di komputer Anda:
1. *Clone* repositori ini atau unduh file ZIP-nya.
2. Pastikan file `index.html`, `style.css`, dan `script.js` berada dalam satu folder.
3. Klik dua kali pada file `index.html` untuk langsung membukanya di browser favorit Anda.
